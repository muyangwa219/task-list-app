# Task List Application

## Project Description
This project was created for Task 2 of the Git assignment. The goal of the task was to extend a simple task list application using Git version control and Git branching.

## Features
- Task list stored in a text file (tasks.txt)
- Priority levels for tasks (High, Medium, Low)
- Git branching used to implement a new feature

## Git Concepts Demonstrated
- Git repository initialization
- Creating and switching branches
- Staging and committing changes
- Viewing commit history

## Branch Used
The feature was developed using a branch called:
feature-priority
